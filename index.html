Blake Hash

Blake Hash is a Progressive Web App (PWA). You can add this website to your phone or computer and use it like an app for quick access to the live Blake network hashrate.

iPhone / iPad

  1. Open this page in Safari.
  2. Tap the Share button.
  3. Tap Add to Home Screen.
  4. Make sure Open as Web App is enabled.
  5. Tap Add.

Android

  1. Open this page in Chrome.
  2. Tap the browser menu ⋮.
  3. Select Install app or Add to Home screen.
  4. Confirm.

Windows / Mac / Linux

  1. Open this page in a supported browser.
  2. Use the browser's Install option or Add to desktop option.
  3. Confirm.

Once added, Blake Hash will appear on your device like an app, giving you quick access to the live network hashrate.
